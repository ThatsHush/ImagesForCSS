ImagesForCSS

Static image assets hosted with GitHub Pages for use in CSS themes. Click an image to open it directly, or copy the direct URL / CSS line.

How to use

--background-image-url: url('https://thatshush.github.io/ImagesForCSS/backgrounds/your-image.png');

Upload future backgrounds into the backgrounds/ folder. Then add one entry to the image list inside this page.
